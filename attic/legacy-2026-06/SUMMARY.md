## 1. Цель проекта

Собрать и нормализовать базу школ с `mathex.ru/shkoly/`, геокодировать адреса, добавить частные школы из рейтинга Forbes, подготовить артефакты для ручного импорта в Яндекс.Конструктор карт (с цветовой сегментацией по ценовым категориям).

---

## 2. Что сделано

### 2.1. Сбор данных
- **Mathex (12 школ)** — собраны с отдельных страниц `/shkoly/<slug>/`, адреса и координаты извлечены из JSON-state карточек Яндекс.Карт (`/maps/org/.../...`).
- **Mathex-extra (6 школ)** — добавлены по запросу пользователя из раздела `/shkoly/drugie-top-school/`: Университетская гимназия МГУ, Школа 1568, Школа 1534, Школа 1514, Курчатовская школа, Силаэдр. Org_id найдены через Я.Карты `?text=...&type=biz`.
- **Forbes (51 школа)** — распарсены 3 файла `simplescraper-www-forbes-ru-*.json` (LOW/MID/HIGH сегменты), отфильтрованы нон-школы (Beat Film Festival, "Правила выбора"), извлечены адреса, цены, годы основания.
- **Дедупликация:** Летово и Школа ЦПМ оставлены из Mathex (полнее), данные Forbes перенесены в `notes`.

### 2.2. Геокодирование
- API: Яндекс.Карты HTTP Geocoder (`geocode-maps.yandex.ru/1.x/`), API key `c137307d-***`.
- Все **69 школ** геокодированы, `precision=exact`, `kind=house` (для московских адресов).
- **Главная ловушка:** кириллица в URL обязательно должна быть `urllib.parse.quote()`-encoded, иначе HTTP 400 без тела.

### 2.5. UX-улучшения карточки (по итеративной обратной связи)
- **label (iconCaption) ≤ 9 символов** через словарь сокращений (`ГСВВ`, `Л2Ш`, `Воробёвы`, `Brit.Int.`, `Зол.сеч.` и т.д.).
- **description** — без `<b>` (жирного) на адресах, без "Сегмент/Основана/Приоритетные ценности".
- **Структура description:**
  - Mathex-школа: `name\n\nадрес\nСайт: <a>...</a>\nСтраница на Mathex`
  - Forbes-школа: `name\n\nадрес\nЦЕНА руб/год\nСайт: <a>...</a>`
- **Цвета** через `properties.marker-color` (стандарт geojson.io, читается Я.Картами):
  - Mathex: `#1e98ff` (синий)
  - LOW: `#ffd21e` (жёлтый)
  - MID: `#ff7800` (оранжевый)
  - HIGH: `#ef3c4a` (красный)
- **Сайты** для 51 Forbes-школы (раньше были только у Mathex).
- **Круглые метки** — задаются в UI Я.Конструктора (`Стиль слоя → Круглый значок`), не через GeoJSON.

## 3. Потенциал для развития

### 3.1. JS API v2.1 с фильтрами (мини-проект, отдельный)
**Что это:** HTML-страница с Яндекс.Картой (через `api-maps.yandex.ru/2.1/`), где можно фильтровать школы по:
- сегменту (low / mid / high / mathex)
- источнику (mathex / forbes)
- диапазону цены
- наличию нескольких корпусов
- округу Москвы / Подмосковью

**Что даст:**
- Чекбоксы / ListBox в углу карты для интерактивной фильтрации.
- `clusterer` для группировки близких меток на малых масштабах.
- `Balloon` с rich-content (картинки, отзывы).
- Поиск по названию.
- Custom layout для нестандартных карточек.

**Что потребуется:**
- ~200 строк HTML/JS в одном файле `schools_map.html`.
- API-ключ `c137307d-***` уже есть.
- Хостинг (GitHub Pages / VPS / локально).
- В `schools.geojson` нужно добавить `properties.segment` и `properties.source` (5 минут работы).

**Оценка трудоёмкости:** 30–60 минут.

### 3.2. Расширение источников
- **Школы, не включённые в финальную базу:**
  - "Проект 2*2" и "Воробьевы Горы маткласс на Донской" — у Mathex нет адресов, нужен ручной сбор.
- **Другие рейтинги:**
  - Рейтинг Департамента образования Москвы (`rating.mos.ru/dpo`).
  - RAEX (`raex-a.ru`).
  - Школьные секции mskobr.ru.
- **За пределами Москвы:** расширить на Санкт-Петербург, Казань и т.д.

### 3.3. Обогащение данных
- **Средний балл ЕГЭ** выпускников (с сайтов школ).
- **Количество призёров ВсОШ** за последние 3 года.
- **Размер класса**, год основания (частично есть).
- **Преподаватели** (топовые олимпиадные тренеры).
- **Стоимость обучения в месяц** (для платных) — пересчёт из годовой.

### 3.4. Автоматизация
- **Cron-задача** на обновление: парсить Mathex + Forbes раз в месяц, детектить новые школы и изменения адресов/цен.
- **Telegram-бот** для добавления школ голосом (отправляешь адрес + название → бот геокодирует → добавляет в CSV).
- **GitHub Actions** на регенерацию `schools.geojson` при изменении `schools_normalized.csv`.

### 3.5. Альтернативные визуализации
- **Тепловая карта** плотности школ.
- **Изохроны** (15/30/45 минут пешком от метро) — какие школы в пешей доступности.
- **Маршруты** между школами (Polyline на карте).
- **Story map** (Mapbox Story или Yandex MapKit Stories) с нарративом про каждую школу.
- **Статичная веб-страница** (mkdocs / hugo) с встроенной картой и таблицей с фильтрами.

### 3.6. Дополнительные форматы экспорта
- **KML** (Google Earth / Google My Maps).
- **Waze Community** формат.
- **2GIS** Atlas.
- **OSM-импорт** (но требует тщательной модерации сообществом).

### 3.7. Качество данных
- **Валидация адресов** через dadata.ru (исправление опечаток, нормализация).
- **Проверка существования школ** (парсинг ЕГЭ-выпусков, чтобы школа не закрылась).
- **Доверительные интервалы** к ценам (разброс указан, но не фактический).
- **Экспертная модерация** — пригласить репетиторов/родителей для оценки.

### 3.8. UX-улучшения карточки
- **Иконки** (МШ-формат, метки "топ-10", "бесплатная" и т.д.).
- **Hover-эффект** на JS API.
- **Pop-up с ближайшими школами** (топ-5 в радиусе 2 км).
- **Сравнение школ** (бок о бок) — таблица с фильтрами.

## 5. Технические долги

- **Скрипт генерации** всех выходных файлов не вынесен в отдельный `build.py` — логика размазана по нескольким execute_code-блокам в истории. При следующем изменении данных придётся повторять вручную.
- **Словарь сокращений `SHORTEN_MAP`** — 50+ хардкод-записей, нет автоматического алгоритма. Если добавится новая школа — ручная правка.
- **Словарь сайтов `FORBES_SITES`** — 51 запись, частично может быть неточной (не проверял все URL вручную).
- **Нет CI** — нет тестов на корректность geojson, на валидность цветов, на соответствие формата import_yandex требованиям Я.Конструктора.
- **Версия API-ключа** захардкожена в нескольких местах истории чата; в финальные файлы не попала (хорошо).
