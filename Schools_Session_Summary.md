# Schools Session Summary

## Размещение адресов и обратных ссылок

Отдельные карточки между картой и Markdown-разделом удалены. Адреса и обратные ссылки теперь встраиваются непосредственно в соответствующие описания исходных Markdown-файлов.

Для каждой школы или детского сада отображается единый адресный блок:

- адрес;
- ссылка «↗ Показать на карте»;
- связанная школа для детского сада;
- источник адреса, если он указан.

Больше нет отдельных разделов «Данные карты: адреса и переходы к точкам (школа)» и «Данные карты: адреса и переходы к точкам (детский сад)».

## Архитектура

`places.json` остаётся единым источником картографических данных. JavaScript группирует объекты по `group`/`associated_school` и добавляет адресный блок сразу после соответствующего абзаца исходного Markdown-описания. Если точное описание не найдено, блок добавляется в конец соответствующего Markdown-раздела, поэтому данные не теряются.

## Откат

Предыдущая версия сохранена в Git. Новая версия публикуется отдельным commit; для отката использовать предыдущий commit или `git revert` нового commit.

## Проверка

- карточные контейнеры удалены из `index.html`;
- отдельные технические секции адресов удалены;
- адресные блоки создаются внутри Markdown-разделов;
- обратная ссылка открывает точный маркер на карте;
- `places.json` содержит 51 объект с уникальными идентификаторами.

Адреса перед поездкой или подачей документов следует перепроверять по официальным сайтам организаций.
