# Schools Session Summary

## Проверка адресов

Состав данных проверен по официальным страницам, когда они доступны. Адреса в `places.json` теперь могут содержать несколько корпусов одной организации; каждый корпус — отдельная точка.

### Хорошкола

По официальной странице контактов:

- прогимназия, 1–4 классы: Москва, улица Народного Ополчения, 7А;
- гимназия, 5–11 классы: Москва, улица Народного Ополчения, 9А;
- детский сад: Москва, улица Маршала Тухачевского, 45к2.

Это три отдельные точки и три карточки, объединённые группой `Хорошкола`.

### Ломоносовская школа

По официальной карте сети:

- начальная городская школа: Москва, Можайское шоссе, 31к2;
- основная и старшая школа: Москва, Аминьевское шоссе, 18к4;
- дополнительный корпус: Москва, улица Кременчугская, 44к5;
- отдельный детский сад на Рублёвке: Московская область, Одинцовский район, село Успенское, Советская улица, стр. 50.

### ЛИТ

По официальной странице контактов:

- 9–11 классы: Ломоносовский проспект, 16;
- 5–8 классы: Профсоюзная улица, 24к4;
- начальная школа: улица Кржижановского, 4А.

## Архитектура

`places.json` — редактируемый слой данных. Поля `group` и `associated_school` используются для визуальной группировки связанных карточек; координаты каждого корпуса остаются независимыми.

Перед изменением адресов нужно сначала проверить официальную страницу контактов организации, затем обновить адрес и координаты в `places.json`.

## Проверка

После изменения запускать проверку уникальности `id`, наличия координат и отличия координат у заведомо разных зданий. Публиковать одновременно `index.html`, `app.js`, `places.json` и этот summary в ветку `gh-pages`.
