# Schools Session Summary

## Версия без промежуточных карточек

В новой версии убраны отдельные карточки между картой и исходными Markdown-описаниями.

После карты сразу открывается раздел:

**«Исходные описания из Markdown-файлов»**

Адреса, тип объекта, связанные школы, примечания и ссылки обратно на карту добавляются в этот раздел динамически из `places.json`.

Для каждого объекта добавляется ссылка:

**↗ Показать на карте**

Она центрирует карту, увеличивает масштаб, открывает нужный popup и прокручивает страницу к карте.

## Откат

Предыдущая рабочая версия сохранена в Git перед публикацией новой версии. Для отката использовать предыдущий commit или `git revert` нового commit.

## Архитектура

- `places.json` — единый источник данных карты;
- `index.html` — карта и раздел исходных описаний;
- `app.js` — карта, popup и динамические адресные блоки в Markdown-разделе;
- Markdown-файлы — исходные редакционные тексты.

Код не дублирует адреса в HTML: адреса и обратные ссылки строятся из `places.json`.

## Проверка

Проверено:

- в `places.json` 51 объект;
- все `id` уникальны;
- у всех объектов есть адрес и координаты;
- карточные контейнеры между картой и Markdown-разделом удалены;
- адресные блоки и ссылки строятся после загрузки Markdown.

Перед поездкой или подачей документов адреса следует перепроверять по официальным сайтам организаций.
