# Schools Session Summary

## Проверка адресов

Состав данных проверяется по официальным страницам организаций. Для разных корпусов используются отдельные объекты и отдельные координаты.

### Летово

Официальная страница «Сведения об образовательной организации» подтверждает три места осуществления образовательной деятельности:

- детский сад «Летово Кидс»: Москва, улица Дубининская, 59А;
- «Летово Джуниор»: Москва, Раменский бульвар, 1А, строение 1;
- основная школа «Летово»: Москва, район Коммунарка, улица Зимёнковская, 3.

В `places.json` они представлены тремя отдельными объектами группы `Летово`. Детский сад отмечен зелёным, «Летово Джуниор» — зелёным как начальная/дошкольная траектория, основная школа — красным.

Источники:

- https://letovo.ru/o-shkole/svedenia-ob-obrazovatelnoy-organizacii
- https://letovo-kids.ru/
- https://letovojunior.ru/

## Архитектура

`places.json` — редактируемый слой данных. Поля `group` и `associated_school` используются для визуальной группировки связанных карточек; координаты каждого корпуса остаются независимыми.

Перед изменением адресов нужно сначала проверить официальную страницу контактов организации, затем обновить адрес и координаты в `places.json`.

## Проверка

После изменения запускается проверка уникальности `id`, наличия координат и отличия координат у заведомо разных зданий. Публикуются одновременно `index.html`, `app.js`, `places.json` и этот summary в ветку `gh-pages`.

Адреса могут изменяться; перед поездкой или подачей документов их следует перепроверять.
