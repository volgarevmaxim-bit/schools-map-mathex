# Школа №179 (Школа Константинова) — образовательные маршруты для родителей

Школа №179 — государственная физико-математическая школа в самом центре Москвы (адрес: ул. Большая Дмитровка, д. 5/6, стр. 7, м. Охотный ряд). Известна как «Школа Константинова» по имени основателя московских матклассов Николая Николаевича Константинова (1932–2021). Топ-20 школ Москвы, грант мэра в сфере образования первой степени (2024/25 и 2025/26 учебные годы). Школа с 7 по 11 класс. Основной канал — 160 постов за 14.08.2025 – 02.10.2026 (89 непустых).

**Особенность 179: основатель матклассов.** Николай Николаевич Константинов — создатель «системы листочков» (индивидуальные задания по математике, по которым учились поколения матшкольников), основатель Турнира им. М. В. Ломоносова и Турнира городов, один из создателей Независимого московского университета. Школа — прямой наследник этой традиции: ученики пишут «листочки» (индивидуальные работы по математике), в школе проводится тур Турнира городов, и сама школа является базой для 89-й Московской математической олимпиады.

**Набор (по посту 15.02.2026):** в 7, 8, 9 математические классы; в 7 математико-технический (бывш. инженерный, регистрация с 13 февраля по 1 марта); в 9 биолого-математический. Прямой ссылки на правила приёма в канале не было — основной канал больше про жизнь школы, нежели про набор. **Вероятно, вступительные и регистрация идут через сайт школы 179.mskobr.ru** (по аналогии с другими московскими школами).

**Олимпиадные достижения (2025/26):** 20 дипломов заключительного этапа ВсОШ по математике (4 победителя + 16 призёров), дипломы по экономике, обществознанию, информатике, биологии, географии, истории, астрономии. Золотая медаль на 56-й Международной физической олимпиаде (Иван Пругло, выпускник 11Б). Серебро на Международной юниорской географической олимпиаде (Матвей Соколов, 10Б). По уровню — сопоставимо с Л2Ш и 1535, с акцентом на математику.

**Подготовительный трек «Вечерний маткласс»** — традиционные кружки для учеников 8-х классов других школ города. Руководитель — Александр Прокофьевич Романов. Запись через mos.ru. Это **программа до основного трека** — бесплатные занятия по математике для сильных учеников.

**Другие кружки и секции:** когнитивные науки, современный мечевой бой (СМБ, «Excolere optima»), ушу-туйшоу, вокальный класс, класс танцев (балы), пряничная мастерская, школьный хор, театр «Чудо», астрономический факультатив. Запись через mos.ru.

## 1. Чтобы попасть в Школу 179, готовиться надо заранее

Приёмная кампания в 179 — это **набор в 7, 8, 9 классы** с фокусом на математику, плюс 7 математико-технический (бывш. инженерный) и 9 биолого-математический. **Опции для занятий и подготовки к поступлению:**

- **Кружки по астрономии, физике, когнитивным наукам** — олимпиадная траектория. Запись через mos.ru.
- **Самоподготовка по «листочкам»** — традиционная система Н. Н. Константинова. Доступны сборники прошлых лет.

## 2. Что сдаётся на вступительных

В 179 **математика — единственный экзамен** для математических классов. Для биолого-математического добавляется биология. Формат — **2 тура**:

**Математический профиль (7, 8, 9 классы):**
- **1-й тур — математика письменно.** Несколько задач, время фиксированное. По уровню — олимпиадная, не школьная. Варианты прошлых лет (2020–2023) есть в открытом доступе.
- **2-й тур — математика устно.** Собеседование с преподавателем. Проверяют **умение объяснить решение вслух и ответить на дополнительные вопросы** — как и в Л2Ш. Это решающий тур. Варианты 2022–2023 доступны.

**Биолого-математический профиль (9 класс):**
- 1-й тур — математика письменно (тот же)
- 2-й тур — **2 собеседования по биологии**

**По аналогии с Л2Ш:** по 2 попытки на каждый зачёт, третьей нет. Призёры заключительного этапа ВсОШ могут быть освобождены от части испытаний (как в Л2Ш).

**Регистрация:** на сайте школы 179.mskobr.ru (точные сроки публикуются в январе–феврале). В 2026 году регистрация на 7 математико-технический (бывш. инженерный) была с 13 февраля по 1 марта.

## 4. Образовательные форматы Школы 179

### 4.1. Основной трек (обучение в Школе 179)

Школа с 7 по 11 класс. Фокус — **математика, физика, информатика**, с сильной гуманитарной составляющей (вокал, театр, танцы, литература). Профили:
- **7–9 математические классы** — углублённая математика с 7 класса, физика и информатика с 8–9
- **7 математико-технический** (бывш. инженерный) — математика + физика + информатика, проектная деятельность
- **9 биолого-математический** — математика + биология + химия
- **10–11 классы** — профильное обучение, проектная деятельность (10 кл. — обязательная), 89-я ММО и заключительный этап ВсОШ

**Традиции, которые отличают 179 от других школ:**
- **«Листочки» Н. Н. Константинова** — индивидуальные задания по математике, по которым ученики занимаются всю среднюю школу
- **День математика** — традиционный праздник школы 21 февраля, с лекциями для школьников и конференцией
- **Балы** — уроки танцев, балы в актовом зале, Октябрьский бал, Кошачий бал, новогодний бал
- **Турнир городов** — 179 — база для школьного и заключительного устного тура
- **89-я ММО** — точка проведения Московской математической олимпиады
- **Театр «Чудо»** — школьный театр, ставит «Маленького принца»
- **Школьный хор** — смешанный, открыт для школьников, родителей и учителей
- **Вокальный класс** — регулярные концерты и фестивали
- **Пряничная мастерская** — традиция А. В. Базаровой

**Олимпиадные результаты 2025/26 (по постам):**
- 20 дипломов заключительного этапа ВсОШ по математике (4+16)
- Дипломы по экономике, обществознанию, информатике, биологии, географии, истории, астрономии

- Множество дипломов ММО, Турнира городов, ЛКТГ

## Приложение Б. Как скачать новые каналы элегантно

Desktop-экспорт из Telegram Desktop — оптимальный путь без риска flood wait. Открыть канал → меню (три точки) → «Экспорт истории чата» → сохранить в `Downloads\Telegram Desktop\ChatExport_<дата>\<имя_канала>.json`. Метод:
- Не дёргает по одному сообщению через API.
- Не требует user credentials или сессии Telethon.
- Автоматически разрешает все медиа-файлы.
- Подходит для одного канала за разумное время (160 постов Школы 179 скачалось за 2–3 минуты).

Для массовой загрузки >10 каналов подряд — между экспортами делать паузу 5–10 минут, чтобы Telegram не флагнул антифрод. Признак флага — запрос подтверждения по SMS при следующем экспорте.
