# Лучшие детские сады и школы Москвы

Одностраничный HTML5-сайт с интерактивной картой и описаниями школ/детских садов из Markdown-источников.

## Открыть сайт

GitHub Pages: `https://volgarevmaxim-bit.github.io/schools-map-mathex/`

## Возможности

- карта Leaflet/OpenStreetMap;
- зелёные маркеры — детские сады и связанные школы;
- синие — школы с приёмом с 1 класса;
- красные — остальные школы;
- фильтр четырёх режимов;
- клик по маркеру ведёт к карточке ниже;
- все корпуса исходной геобазы сохранены отдельными точками;
- исходные Markdown-файлы доступны на странице.

## Файлы

- `index.html` — интерфейс;
- `app.js` — сгенерированные данные и логика карты;
- `schools.geojson` — геоточки и корпуса;
- `build_data.py` — пересборка `app.js`;
- `Лучшие школы Москвы.md`, `Лучшие детские сады Москвы.md` — источники;
- `Schools_Session_Summary.md` — журнал решений и инструкция обновления;
- старые CSV/XLSX/GeoJSON сохранены для совместимости и отката.

## Быстрое обновление

```bash
python build_data.py
python -m http.server 8000
```

Затем проверить `http://localhost:8000/` и закоммитить изменения.

## Источники и актуальность

Тексты взяты из предоставленных пользователем Markdown-файлов. Адреса и набор корпусов следует перепроверять перед подачей документов.
