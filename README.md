# Лучшие школы Москвы на 2026г

Статический сайт с картой школ и дошкольных программ Москвы/ближнего Подмосковья.

## Файлы

- `index.html` — оболочка страницы, карта и сворачиваемые разделы;
- `app.js` — логика Leaflet, фильтры, обратные ссылки и таблица;
- `places.json` — канонический слой точек карты: одна физическая локация — один объект;
- `schools_content.json` — отдельный редактируемый контент под картой: одна школа/дошкольный объект — один абзац;
- `build_places.py` — проверка картографических данных;
- `handoff.md`, `Schools_Session_Summary.md` — журнал и инструкция проекта.

## Локальная проверка

```bash
node --check app.js
python -m http.server 8000
```

Откройте `http://localhost:8000/`. Для корректной загрузки JSON нужен HTTP-сервер, а не `file://`.

## Модель данных

`places.json` остаётся источником истины для карты. Разные корпуса, школы и детские сады не сливаются. В `schools_content.json` каждый абзац перечисляет все связанные точки и содержит минимальную стрелку `↟` для возврата к карте.

Все неизвестные или не перепроверенные сведения помечены прямо в тексте: `не найдено`, `не подтверждено`, `нужно уточнить`. Стоимость частных школ дана индикативно и требует проверки перед заявкой.

## Публикация

GitHub Pages настроен на ветку `gh-pages`. После коммита в `main` нужно обновить опубликованную ветку и проверить live-версии `index.html`, `app.js`, `places.json` и `schools_content.json`.
